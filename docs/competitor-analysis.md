> **Честное ограничение.** Из этой среды нет доступа к Telegram/Instagram, а автоматический парсинг Instagram запрещён условиями Meta и технически блокируется. Поэтому документ даёт: (1) список конкурентов для анализа, (2) методику и метрики, (3) инструмент полуавтоматического сбора по Telegram (`scripts/telethon_scan.py`, легально — только публичные каналы через MTProto), (4) таблицу `data/competitors.csv`, которую вы заполняете; данные отображаются и редактируются в дашборде (вкладка «Конкуренты»). Выводы §4–5 — отраслевые закономерности ниши; после заполнения таблицы агент пересчитает их по реальным цифрам.

## 2. Что измеряем по каждому

**Telegram** (собирает `scripts/telethon_scan.py` автоматически): подписчики; постов/неделю; средние просмотры поста; ER = (реакции+пересылки)/подписчики; форматы (текст/фото/видео/альбом); наличие кнопок; 3 самых просматриваемых поста за месяц.

**Instagram** (вручную, 15 мин на аккаунт раз в месяц): подписчики; постов и Reels/неделю; медианные лайки и комментарии на пост (по последним 9); лайки/подписчики (%); визуальный стиль (единый шаблон? да/нет); офферы и цены с последних 5 продающих постов.

Результаты — в `data/competitors.csv` (импорт в дашборд) либо сразу в дашборде.

## 3. Методика выводов

1. Ранжировать по ER, а не по подписчикам (накрутки в нише повсеместны).
2. У топ-3 по ER разобрать 5 лучших постов: рубрика, хук, структура, визуал, CTA.
3. Зафиксировать «слепые зоны» — рубрики/форматы, которые никто не делает системно.

## 4. Типовые слабости конкурентов ниши (проверить по данным)

1. Прайс-листы вместо контента: «Дубай 5 ночей $650» без картинки желания — низкий ER.
2. Нет единого визуального стиля — лента не узнаваема, сохранений мало.
3. Reels либо нет, либо перезалитые чужие видео без субтитров.
4. Нет рубрик доверия (отзывы с лицами, закулисье) — только продажа.
5. CTA «пишите в директ» без кнопок и без скорости ответа.
6. Хэштеги случайные или отсутствуют; alt-текстов нет ни у кого.
7. Посты выходят рывками (5 в день, потом неделя тишины).
8. Не отрабатываются комментарии — вопросы висят без ответа сутками.

## 5. 10 идей отстройки Oskar Travel

1. **Единый кинематографичный визуал** (Higgsfield + бренд-обложки) — узнаваемость ленты за 2 сек.
2. **«Сценарий отдыха» вместо прайса**: каждый горящий тур — мини-история (утро/день/вечер) + цена + кнопка.
3. **Гайды-пересылки**: «Что взять в Дубай в июле», «Виза в ОАЭ за 3 шага» — органический рост TG.
4. **Отзывы с видео клиентов** + фирменная обложка — рубрика, которой нет у локальных.
5. **Скорость ответа как оффер**: «Ответим за 15 минут» прямо в постах.
6. **Reels с субтитрами на русском/узбекском** — двойной охват аудитории.
7. **Прозрачное ценообразование**: «что входит/что не входит» в каждом туре — снимает главный страх.
8. **Опросы и интерактив** в TG раз в неделю — алгоритмическая видимость.
9. **Сезонный календарь**: серия «Куда лететь в сентябре» за 6 недель до сезона — SEO внутри TG-поиска.
10. **Акция «для подписчиков»** раз в месяц — конверсия охвата в подписку.

## 6. Как собрать данные Telegram автоматически

```bash
pip install telethon
# получите api_id/api_hash на https://my.telegram.org → API development tools
export TG_API_ID=... TG_API_HASH=...
python scripts/telethon_scan.py @asiatraveluz @poytaxttravel @oskartravel
# → выведет CSV-строки в формате data/competitors.csv и файл data/tg_scan.json
```

Скрипт читает только публичные каналы от вашего имени (MTProto). Это разрешено, но не злоупотребляйте частотой — раз в неделю достаточно.
