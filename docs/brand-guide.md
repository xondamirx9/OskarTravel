# Бренд-гайд Oskar Travel (визуальный стиль контента)

Единый стиль для: обложек Reels/видео (в т.ч. сгенерированных в Higgsfield), постов Instagram, постов Telegram, каруселей. Реализован в HTML/CSS-шаблонах `templates/covers/` — правки стиля делаются там и применяются ко всему будущему контенту сразу.

## 1. Палитра (из фирменного стиля сайта)

| Роль | Цвет | HEX |
|---|---|---|
| Тёмный фон / оверлей | глубокий синий | `#182948` (тёмнее: `#0f1d31`) |
| Акцент / бейджи / цена | бронза | `#C56B2C` |
| Текст на тёмном | кремовый | `#F2ECDF` |
| Вторичный текст | серо-голубой | `#8899AA` |
| Успех (бейдж «виза не нужна» и т.п.) | зелёный | `#2ECC71` |

Правило: фоновое фото всегда затемняется градиентом `rgba(15,29,49, .15→.85)` снизу — текст всегда читается, лента едина по тону.

## 2. Типографика

- **Логотип-акцент**: Georgia Italic — курсивная «O» (как на сайте) + OSKAR TRAVEL капителью, letter-spacing 4px.
- **Заголовки**: системный гротеск (-apple-system/Segoe UI), вес 800, сжатый интерлиньяж 1.05.
- **Цена**: вес 900, цвет бронза, всегда с префиксом «от».
- Заголовок обложки ≤ 2 строк; на 1080×1920 кегль 96–120px, на 1080×1350 — 80–96px, на 1280×720 — 64–72px.

## 3. Композиция

- Сетка: поля 7% от короткой стороны со всех сторон; логотип — всегда верхний левый угол; бейдж рубрики — верхний правый.
- Нижняя треть: заголовок → направление/длительность → плашка цены + CTA.
- Бейджи: скруглённые 999px, бронза для «🔥 Горящий тур», синий полупрозрачный для остальных рубрик.
- Фото/видео-кадр: горизонт ровный, главный объект в верхних 2/3 (нижняя треть уходит под текст).

## 4. Форматы (шаблоны)

| Файл | Размер | Назначение |
|---|---|---|
| `reels-1080x1920.html` | 1080×1920 | обложка Reels / вертикального видео (в т.ч. Higgsfield) |
| `ig-post-1080x1350.html` | 1080×1350 | пост Instagram |
| `tg-post-1280x720.html` | 1280×720 | пост Telegram |
| `carousel-1080x1350.html` | 1080×1350 | слайд карусели (титульный/контентный/финальный CTA) |

Переменные шаблонов (`{{...}}`): `title`, `destination`, `duration`, `price`, `badge`, `photo` (URL/путь фонового кадра), `cta`, `slideNo`, `slideText`. Пустые переменные скрывают свой блок.

## 5. Согласованность с Higgsfield

Каждый промпт для Higgsfield (генерирует `agent/content/higgsfield.js`) включает фиксированный стилевой блок: тёплый закатный свет или golden hour, кинематографичная камера (медленный dolly/parallax), насыщенные но естественные цвета с тёплыми полутонами под бронзовый акцент бренда, без текста в кадре (текст добавляет обложка). Так видео из Higgsfield и статичные обложки выглядят одной серией.

## 6. Рендер

```bash
node templates/covers/render.js reels-1080x1920 out.png --title "Дубай за $899" --destination "ОАЭ · 5 ночей" --price "от $899" --badge "🔥 Горящий тур" --photo /path/bg.jpg
```

Дашборд делает то же самое кнопкой «Сгенерировать обложку» у поста.
