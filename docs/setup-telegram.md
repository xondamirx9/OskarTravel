# Настройка публикации в Telegram (пошагово)

Займёт ~5 минут. Нужен ваш Telegram-канал (например, @oskartravel).

## 1. Создайте бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot` → задайте имя (например, `Oskar Travel Publisher`) и username (например, `oskartravel_bot`).
3. BotFather пришлёт **токен** вида `1234567890:AAE...xyz` — это `TELEGRAM_BOT_TOKEN`.

## 2. Сделайте бота администратором канала

1. Откройте свой канал → Управление каналом → Администраторы → Добавить администратора.
2. Найдите своего бота по username и добавьте.
3. Достаточно одного права: **«Публикация сообщений»** (Post messages). Остальные можно выключить.

## 3. Узнайте ID канала

Для публичного канала достаточно username:

```
TELEGRAM_CHANNEL_ID=@oskartravel
```

Для приватного канала — числовой ID: перешлите любой пост канала боту [@userinfobot](https://t.me/userinfobot) или откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` после добавления бота — ID выглядит как `-1001234567890`.

## 4. Заполните .env

```
TELEGRAM_BOT_TOKEN=1234567890:AAE...xyz
TELEGRAM_CHANNEL_ID=@oskartravel
```

## 5. Проверка

```bash
curl -s "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/getChatMemberCount?chat_id=$TELEGRAM_CHANNEL_ID"
```

Должно вернуть `{"ok":true,"result":<число подписчиков>}`. После этого дашборд сможет публиковать посты и ежедневно собирать число подписчиков.

## Ограничения, о которых стоит знать

- Bot API **не отдаёт просмотры и реакции** постов — для них либо вносите цифры раз в неделю вручную (вкладка «Аналитика» → «Внести вручную»), либо запускайте `scripts/telethon_scan.py` для своего канала.
- Лимит ~20 сообщений/мин в один канал — при постинге по расписанию недостижим.
- Подпись к фото/видео — до 1024 знаков; более длинный текст агент публикует как текстовое сообщение (до 4096) без обложки или обрезает подпись.
