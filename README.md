# Oskar Travel — сайт + автономный маркетинговый агент

Монорепозиторий: сайт турагентства с админкой **и** маркетинговый агент, который планирует контент, пишет посты (Telegram + Instagram), готовит промпты для Higgsfield, рендерит брендированные обложки, публикует по расписанию и учится на аналитике.

## Структура

| Путь | Что это |
|---|---|
| `server.js`, `public/index.html`, `public/admin.html` | сайт и админка (как были) |
| `public/marketing.html` | **дашборд маркетингового агента** |
| `agent/` | модули агента (контент, публикация, аналитика, планировщик) |
| `templates/covers/` | HTML-шаблоны обложек + рендер (Playwright) |
| `docs/` | стратегия, архитектура, бренд-гайд, анализ конкурентов, инструкции по токенам |
| `data/marketing/` | данные агента (JSON, создаются автоматически, в git не попадают) |
| `scripts/telethon_scan.py` | опциональный сбор статистики TG-каналов |
| `logs/agent.log` | журнал действий агента (JSONL) |

## Быстрый старт (локально)

```bash
npm install
npx playwright install chromium   # браузер для рендера обложек (если не предустановлен)
cp .env.example .env              # заполните ключи (см. ниже)
npm start
```

- Сайт: http://localhost:3000
- Админка сайта: http://localhost:3000/admin.html
- **Дашборд маркетинга: http://localhost:3000/marketing.html** (пароль — тот же, что у админки; по умолчанию `admin123`, смените в админке → Настройки)

Без единого токена платформа уже работает: генерирует план и черновики (шаблонные тексты вместо LLM), рендерит обложки, ведёт очередь модерации. Токены добавляют: качественные тексты (Claude), публикацию (TG/IG), автоматический сбор метрик.

## Переменные окружения (`.env`)

| Переменная | Обязательна | Описание |
|---|---|---|
| `ANTHROPIC_API_KEY` | для LLM-текстов | ключ Claude API; без него — шаблонные болванки |
| `ANTHROPIC_MODEL` | нет | модель, по умолчанию `claude-opus-4-8` |
| `TELEGRAM_BOT_TOKEN` | для публикации в TG | токен бота (`docs/setup-telegram.md`) |
| `TELEGRAM_CHANNEL_ID` | для публикации в TG | `@username` или `-100…` |
| `IG_ACCESS_TOKEN` | для публикации в IG | долгоживущий токен (`docs/setup-instagram.md`) |
| `IG_BUSINESS_ACCOUNT_ID` | для публикации в IG | ID бизнес-аккаунта |
| `PUBLIC_BASE_URL` | для публикации в IG и медиа в TG | публичный HTTPS-домен платформы |
| `PORT` | нет | порт сервера (3000) |
| `CHROMIUM_PATH` | нет | путь к Chromium, если браузер Playwright не ставится штатно |

## Рабочий цикл

1. **«✨ Сгенерировать план на неделю»** в дашборде → агент создаёт черновики по рубрикам и сетке времени из Настроек.
2. **Очередь модерации**: открыть пост → отредактировать тексты → «Сгенерировать обложку» → скопировать промпт Higgsfield → сгенерировать видео в Higgsfield → загрузить файл к посту → **Одобрить**.
3. Публикация: кнопкой «Опубликовать сейчас» или автоматически по расписанию (включите «Автопубликация» в Настройках).
4. **Аналитика** собирается ежедневно в 21:05; просмотры TG вносите вручную или через `scripts/telethon_scan.py`.
5. Каждый понедельник 08:00 агент формирует отчёт и сам корректирует доли рубрик по результатам.

## Деплой

Нужен любой сервер с Node.js ≥ 20 и публичным HTTPS-доменом (домен обязателен для Instagram):

```bash
git clone <repo> && cd OskarTravel
npm install --omit=dev
npx playwright install --with-deps chromium
cp .env.example .env && nano .env      # заполнить токены + PUBLIC_BASE_URL
# запуск под менеджером процессов:
npm i -g pm2
pm2 start server.js --name oskartravel && pm2 save
# reverse-proxy (nginx/caddy) → localhost:3000, HTTPS через Let's Encrypt
```

Бэкапить достаточно `data/` и `public/uploads/`.

## Известные ограничения (по-честному)

- **Higgsfield** не имеет публичного API — агент выдаёт готовый промпт, видео генерируется вручную и загружается к посту в дашборде.
- **Instagram**: ≤50 публикаций/сутки через API (агент считает); медиа — только по публичному URL (нужен деплой); токен живёт ~60 дней — обновляйте по `docs/setup-instagram.md` §4; парсинг конкурентов в IG запрещён Meta — в дашборде ручной ввод.
- **Telegram Bot API** не отдаёт просмотры/реакции постов — ручной ввод в Аналитике или `scripts/telethon_scan.py` (MTProto).
- Хранилище — JSON-файлы (`data/marketing/`). Для миграции на PostgreSQL достаточно переписать `agent/lib/db.js` (5 функций read/write/update) — весь остальной код от формата хранения не зависит.
